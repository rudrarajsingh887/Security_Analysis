# Outputs

Processed videos and logs are saved here.

| File | Description |
|------|-------------|
| `result.mp4` | Annotated output video from CLI (`main.py`) |
| `streamlit_result.mp4` | Annotated output video from the Streamlit dashboard |
| `run.log` | Debug log from the last CLI run |

These files are excluded from version control via `.gitignore`.
